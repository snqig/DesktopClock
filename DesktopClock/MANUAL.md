# DesktopClock 用户使用手册

DesktopClock 是一款基于 .NET 9 WPF 的 Windows 桌面时钟应用，提供 11 种精美显示模式、自由布局、皮肤系统、提醒、天气与系统监控等丰富功能，帮助你在桌面上随时掌握时间与信息。

## 快速开始

### 1. 下载程序

前往项目的 GitHub Releases 页面，下载最新的 `DesktopClock.exe`（单文件发布版本），保存到任意目录，例如 `D:\Apps\DesktopClock\`。

### 2. 安装 .NET 9 运行时

DesktopClock 依赖 .NET 9 运行时。首次运行若提示找不到运行时，请运行仓库自带的检测脚本：

```powershell
# 在项目根目录下执行
powershell -ExecutionPolicy Bypass -File scripts\check-dotnet.ps1
```

该脚本会检测本机是否已安装 .NET 9 Desktop Runtime，缺失时引导你完成安装。你也可以直接前往 [.NET 官网](https://dotnet.microsoft.com/download/dotnet/9.0) 手动下载并安装 **.NET Desktop Runtime 9.0.x**。

### 3. 启动应用

双击 `DesktopClock.exe` 即可启动。首次启动会以默认的数字时钟模式显示在屏幕右上角，并在任务栏通知区域出现托盘图标。

> 提示：若窗口未出现，请查看 [故障排查](#故障排查) 一节。

## 显示模式介绍

DesktopClock 内置 11 种显示模式，可在 **设置 → 显示 → 显示模式** 中切换，也可通过命令行参数 `--mode=<模式>` 指定（见 [多实例](#多实例)）。

| 模式 | 命令行参数值 | 简介 |
|------|------------|------|
| 数字 | `digital` | 经典电子数字显示，默认模式，字体与颜色可自定义 |
| 翻转 | `flip` | 卡片翻转动画，模拟机械翻页时钟 |
| 文字 | `word` | 以文字网格高亮显示当前时间，文艺风格 |
| 二进制 | `binary` | 二进制点阵显示时分秒，极客专属 |
| 极简 | `minimal` | 极简数字显示，干净纯粹 |
| 模拟 | `progress` | 简约圆盘指针时钟，三针走时 |
| 超精美模拟 | `analog_premium` | 玻璃圆盘 + 旋转光晕 + 轨道点，视觉效果华丽 |
| 机械 | `mechanical` | 金属齿轮表盘 + 铆钉 + 机械指针，工业风 |
| 指针表盘（自定义） | `analog_skin` | 自定义底图与指针，支持 `.dskin` 配置与相册背景 |
| 缎带 | `ribbon` | 流光缎带动效，柔美流动 |
| 双时区 | `dual_analog` | 本地与第二时区并排显示，适合跨时区用户 |

> 说明：「文字」模式目前通过启动参数 `--mode=word` 启用，设置面板的下拉列表中暂未列出。

## 基础操作

### 移动窗口

未锁定位置时，在时钟窗口上 **按住鼠标左键拖动** 即可移动窗口到任意位置。若启用了「锁定位置」，需先在设置或右键菜单中取消锁定。

### 托盘菜单

时钟运行时会在任务栏通知区域显示托盘图标。**右键托盘图标** 可打开托盘菜单：

- **显示/隐藏**：切换时钟窗口的可见性
- **设置**：打开设置面板
- **退出**：完全退出程序（关闭窗口只是隐藏到托盘）

**双击托盘图标** 也可快速切换显示/隐藏。

### 窗口右键菜单

在时钟窗口上 **单击鼠标右键**，可打开更丰富的上下文菜单：

- **切换表盘**：快速切换到任意显示模式
- **窗口置顶 / 取消置顶**：让时钟始终显示在最前
- **编辑布局模式**：进入/退出自由布局编辑（见 [布局模式](#布局模式)）
- **选择颜色**：快速调整字体颜色
- **设置**：打开设置面板
- **重启程序**：一键重启时钟
- **导出配置 / 导入配置**：保存或加载 `.dskin` 表盘配置文件
- **退出**：退出程序

### 全局热键

- **Ctrl + H**：隐藏 / 显示时钟窗口（全局热键，可在设置中自定义）
- **Ctrl + Shift + S**：循环切换表盘模式

### 设置入口

打开设置面板有两种方式：
1. 右键托盘图标 → **设置**
2. 右键时钟窗口 → **设置**

在设置面板中修改选项后，点击 **确定** 保存并应用，点击 **取消** 放弃修改。

## 设置面板详解

设置面板顶部有 5 个分类标签：**显示、外观、日期、功能、系统**。点击标签即可切换到对应面板。

### 显示

时钟的核心显示选项。

- **时制**：12 小时制 / 24 小时制
- **显示秒**：是否显示秒数
- **显示模式**：选择 11 种表盘之一
- **世界时钟**：启用后可在附加时区显示时间，并选择时区
- **第二时区 / 标签**：当选择「双时区指针」模式时，设置第二时区与其显示标签（如「纽约」）
- **整点报时**：每整点播放提示音
- **指针表盘自定义颜色**：当选择「指针表盘（自定义）」时出现，可设置时针 / 分针 / 秒针 / 刻度颜色、指针粗细倍率、是否显示秒针 / 刻度 / 中心圆点

### 外观

控制时钟的字体、颜色、背景与滤镜。

- **字体**：字体名称与字号
- **背景透明度**：窗口背景的不透明度
- **字体颜色**：时钟文字颜色（可手动输入十六进制色值）
- **背景类型**：纯色 / 渐变
  - 渐变可设置起始色、结束色与角度
- **边框**：边框颜色与粗细
- **主题预设**：一键应用 dark / light / green / blue 配色
- **相册背景**：为指针表盘叠加自定义图片背景，可设置图片路径、不透明度、模糊度、拉伸模式
  - 仅在「指针表盘（自定义）/ 缎带 / 双时区」模式下生效，切换到其他表盘会自动关闭
- **窗口背景效果**：Windows 11 下可选择 None / Mica / Acrylic / Tabbed 背景效果
- **全局滤镜**：启用后可调节
  - 暗角（边缘变暗）
  - 灰度（画面去色）
  - 色温（正数偏暖，负数偏冷）

### 日期

日期组件的外观与位置。

- **显示日期**：是否显示日期
- **字体 / 字号 / 颜色**：日期文字样式
- **日期位置**：顶部（top） / 底部（bottom），决定日期相对时钟的位置

### 功能

扩展组件与交互行为的集合，包含多个分组。

- **交互**：
  - 鼠标穿透模式：启用后鼠标点击穿过窗口；按住 **Ctrl** 可临时与窗口交互或拖动
  - 窗口贴边：靠近屏幕边缘自动吸附
  - 锁定位置：禁止拖动窗口
  - 布局模式：自动排列（Stack）/ 自由拖拽（Free），详见 [布局模式](#布局模式)
- **插件**：列出已加载的插件，可勾选启用或禁用
- **快捷键隐藏**：自定义隐藏/显示热键，默认 `Ctrl+H`
- **农历**：显示农历信息，可附加节气、生肖，自定义字号与颜色
- **提醒**：启用定时提醒，可添加 / 编辑 / 删除提醒项，支持单次与按周重复
- **AOD 省电**：启用后系统闲置超过设定分钟数时，自动隐藏秒针并降低窗口亮度
- **跟随系统深色/浅色模式**：自动跟随 Windows 主题切换配色
- **鼠标悬停增强透明度**：鼠标靠近时窗口变得更清晰，离开时恢复
- **系统监控**：显示 CPU / 内存 / 网速 / 电池，可逐项勾选
- **天气**：基于 Open-Meteo API，设置城市、纬度、经度，显示温度、图标与日出日落，支持离线缓存
- **倒计时**：设置目标时间与标签，显示距目标剩余时间
- **待办滚动**：自定义滚动文字与速度，平滑滚动展示
- **音乐播放**：显示当前播放的歌曲信息，可选是否显示歌手
- **自动切换表盘**：按时段自动切换白天 / 夜间表盘，可分别设置白天与夜间起始小时

### 系统

- **开机自启**：勾选后随 Windows 登录自动启动（写入注册表）
- **语言**：切换界面语言，可选 **中文 / English**

## 布局模式

DesktopClock 提供两种布局模式，可在 **设置 → 功能 → 布局模式** 或窗口右键菜单中切换。

### Stack 布局（默认，自动排列）

- 所有启用的组件（日期、农历、时钟、世界时钟、系统监控、天气等）按顺序垂直排列
- 紧凑简洁，组件上方不显示名称标签
- 适合大多数用户，开箱即用

### Free 布局（自由拖拽）

- 每个组件可独立拖拽到窗口内任意位置
- 支持 **锁定**、**删除**、**重置大小** 等操作
- 适合需要个性化排版的高级用户

### 编辑布局模式

进入 Free 布局编辑最便捷的方式：

1. 右键时钟窗口 → **编辑布局模式**
2. 此时提示「已进入编辑模式，可拖拽组件调整位置」
3. 拖动各组件到满意的位置
4. 再次右键 → **编辑布局模式** 退出
5. 退出时提示「已退出编辑模式，布局已保存」，位置自动持久化

> 提示：编辑模式下调整的位置会写入配置文件，下次启动自动恢复。

## 指针表盘（自定义）

「指针表盘（自定义）」是可玩性最高的模式，支持深度自定义。

### 自定义外观

在 **设置 → 显示 → 指针表盘自定义颜色** 中（需先选择该模式）：

- **时针 / 分针 / 秒针颜色**：分别设置三针颜色
- **刻度颜色**：表盘刻度的颜色
- **指针粗细**：0.3x ~ 3.0x 倍率调节
- **显示秒针 / 显示刻度 / 显示中心圆点**：逐项开关

### 皮肤配置（.dskin）

指针表盘的配置可通过 `.dskin` 文件导入导出，方便备份与分享。

- **导出**：右键窗口 → **导出配置**，选择保存路径，生成 `.dskin` 文件
- **导入**：右键窗口 → **导入配置**，选择已有的 `.dskin` 文件，配置立即应用

`.dskin` 文件是 JSON 格式，包含显示模式、字体、颜色、背景、相册背景参数及组件配置等信息。

### 相册背景

为指针表盘叠加一张自定义图片作为背景：

1. 切换到「指针表盘（自定义）」「缎带」或「双时区」模式
2. 在 **设置 → 外观 → 相册背景** 中勾选「启用相册背景」
3. 选择图片路径，调节不透明度、模糊度与拉伸模式

> 注意：相册背景仅在这三种表盘下可用。切换到其他表盘时会自动关闭，避免背景层残留影响显示。

## 多实例

可以同时运行多个独立的时钟窗口，每个实例拥有独立的配置、窗口位置与托盘图标。

通过命令行参数 `--instance=N` 启动新实例（N 为大于 0 的整数）：

```powershell
# 启动实例 1
DesktopClock.exe --instance=1

# 启动实例 2
DesktopClock.exe --instance=2
```

每个实例使用独立的配置文件与位置文件：

- 实例 N 的配置：`settings_instance_{N}.json`
- 实例 N 的位置：`pos_instance_{N}.txt`

主实例（不带 `--instance` 参数）使用 `settings.json` 与 `pos.txt`。

你也可以用 `--mode=<模式>` 启动时直接指定显示模式：

```powershell
# 以翻转时钟模式启动
DesktopClock.exe --mode=flip

# 以文字时钟模式启动实例 1
DesktopClock.exe --mode=word --instance=1
```

## 多语言

DesktopClock 支持三种语言资源：**中文（zh）、英文（en）、日文（ja）**。

- 在 **设置 → 系统 → 语言** 中可切换 **中文 / English**
- 日文资源已内置，但设置面板暂未提供选项。如需启用日文，可手动编辑配置文件，将 `"Language"` 字段改为 `"ja"`：

```json
{
  "Language": "ja"
}
```

修改后重启程序生效。

## 开机自启

让时钟随 Windows 登录自动启动：

1. 打开 **设置**（托盘右键 → 设置）
2. 切换到 **系统** 标签
3. 勾选 **开机自启**

勾选后程序会写入注册表启动项；取消勾选则移除启动项。也可以在命令行运行时通过设置同步自动管理。

## 故障排查

### 窗口不显示

- 检查托盘图标是否存在：若存在，双击托盘图标或右键 → **显示/隐藏**
- 可能被全局热键隐藏：按 **Ctrl + H** 切换显示
- 查看日志文件（见 [数据文件位置](#数据文件位置)），搜索 `Error` 或 `Exception` 排查启动异常
- 尝试右键托盘 → **退出** 后重新启动程序

### 天气不更新

- 检查网络连接是否正常，Open-Meteo API 需要联网获取
- 确认 **设置 → 功能 → 天气** 中的城市、纬度、经度填写正确
- 天气数据有 24 小时缓存：断网时会显示带「(缓存)」标记的最近一次数据
- 若缓存过期或异常，可删除天气缓存文件后重启程序（见 [数据文件位置](#数据文件位置)）

### 切换表盘异常

- 切换表盘后若显示异常，先尝试右键 → **重启程序**
- 查看 `logs\desktopclock.log` 当天日志，搜索相关错误信息
- 若相册背景在非指针表盘下残留，属已知行为：切换到指针表盘可恢复

### .NET 运行时缺失

启动时若弹出「找不到 .NET 运行时」或类似错误：

1. 运行检测脚本：`powershell -ExecutionPolicy Bypass -File scripts\check-dotnet.ps1`
2. 或前往 [.NET 官网](https://dotnet.microsoft.com/download/dotnet/9.0) 下载安装 **.NET Desktop Runtime 9.0.x**
3. 安装完成后重新启动 `DesktopClock.exe`

### 其他问题

- **配置损坏**：备份后删除 `settings.json`，程序会以默认配置重新生成
- **窗口位置丢失**：删除 `pos.txt` 后重启，窗口将回到默认位置
- **崩溃排查**：查看 `crash.log` 与 `logs` 目录下的日志

## 数据文件位置

所有用户数据均存放在 `%LOCALAPPDATA%\DesktopClock\` 目录下，即 `C:\Users\<你的用户名>\AppData\Local\DesktopClock\`。

| 文件 / 目录 | 路径 | 说明 |
|------------|------|------|
| 主配置文件 | `%LOCALAPPDATA%\DesktopClock\settings.json` | 所有设置项，显示模式、字体、颜色、布局、提醒等 |
| 多实例配置 | `%LOCALAPPDATA%\DesktopClock\settings_instance_{N}.json` | 实例 N 的独立配置 |
| 窗口位置 | `%LOCALAPPDATA%\DesktopClock\pos.txt` | 主实例窗口坐标，格式 `Left,Top` |
| 多实例位置 | `%LOCALAPPDATA%\DesktopClock\pos_instance_{N}.txt` | 实例 N 的窗口坐标 |
| 运行日志 | `%LOCALAPPDATA%\DesktopClock\logs\desktopclock.log` | 按天滚动，保留最近 7 天 |
| 崩溃日志 | `%LOCALAPPDATA%\DesktopClock\crash.log` | 未处理异常的冗余备份记录 |
| 天气缓存 | `%LOCALAPPDATA%\DesktopClock\cache\weather.json` | 最近一次天气数据，断网时使用，24 小时过期 |

> 提示：`%LOCALAPPDATA%` 可在文件资源管理器地址栏直接粘贴打开。

日志级别可通过环境变量 `LOG_LEVEL` 调整，可选值为 `Debug / Information / Warning / Error`。

## 常见问题（FAQ）

**Q1：关闭窗口后程序还在运行吗？**
是的。关闭窗口只是将时钟隐藏到系统托盘。如需完全退出，请右键托盘图标 → **退出**，或右键窗口 → **退出**。

**Q2：如何让时钟一直显示在最前面？**
右键时钟窗口 → **窗口置顶** 即可让其始终置顶；再次点击可取消置顶。

**Q3：相册背景为什么在切换表盘后消失了？**
相册背景仅支持「指针表盘（自定义）」「缎带」「双时区」三种模式。切换到其他表盘时会自动关闭以避免背景层残留。切回这三种模式后需重新勾选启用。

**Q4：可以同时显示多个时钟吗？**
可以。使用命令行 `DesktopClock.exe --instance=1`、`--instance=2` 等启动多个独立实例，每个实例的配置与位置互不影响。

**Q5：天气信息一直显示「(缓存)」怎么办？**
这通常意味着网络无法访问 Open-Meteo API。请检查网络连接；待网络恢复后程序会自动刷新最新数据。若长时间不刷新，可删除 `cache\weather.json` 后重启。

**Q6：鼠标穿透模式下无法拖动窗口怎么办？**
鼠标穿透模式下鼠标点击会穿过窗口。按住 **Ctrl** 键即可临时与窗口交互并拖动；松开 Ctrl 恢复穿透。

**Q7：如何备份或迁移我的配置？**
备份 `%LOCALAPPDATA%\DesktopClock\settings.json` 即可。指针表盘的外观配置还可用右键菜单的 **导出配置** 生成 `.dskin` 文件单独保存或分享。迁移到新电脑时，将这些文件放回相同路径即可恢复。

**Q8：程序运行很卡或占用资源高怎么办？**
可尝试：关闭暂时不需要的组件（系统监控、天气、待办滚动等）；启用 **AOD 省电模式** 降低闲置时的刷新负担；或在不需要秒针时关闭「显示秒」以减少刷新频率。
