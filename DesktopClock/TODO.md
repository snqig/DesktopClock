# DesktopClock 开发路线图

## 🚨 P0 紧急开发（当前首要目标）

### 1. 指针表盘 AnalogClockSkin
- [x] 定义统一 `IClockSkin` 表盘接口
- [x] 重构现有表盘代码（新增 `Skins/` 目录，`SkinHost` 统一驱动）
- [x] 实现图片底图 + 矢量指针方案
  - [x] 底图：支持本地 PNG 图片（透明无指针表盘素材）
  - [x] 默认透明底图动态生成（圆环 + 刻度）
  - [x] 时针 / 分针 / 秒针使用 WPF `Line` 矢量绘制
  - [x] 角度计算公式绑定 `RotateTransform`
- [x] 基础配置项：指针颜色、粗细、是否显示秒针
- [x] 中心装饰圆点、刻度渲染（矢量刻度可选开关）
- [x] 测试：窗口缩放矢量元素不失真（`Viewbox` + `Uniform`）

### 2. 相册背景通用能力（所有表盘共用）
- [x] `SkinBackgroundConfig`：图片路径、透明度、模糊程度、拉伸模式
- [x] `SkinHost` 在皮肤视图下方叠加通用相册背景层
- [x] 为其他表盘（数字/翻转/二进制/机械等）接入背景层
  - [x] 新增 `BackgroundWrapper` 通用包装器，可包裹任意 `IClockComponent`
  - [x] `AppSettings` 增加全局相册背景字段（启用/路径/透明度/模糊/拉伸）
  - [x] `MainWindow.RebuildLayout` 在启用背景时用 `BackgroundWrapper` 包裹当前表盘
  - [x] `analog_skin` 模式通过 `SkinHost` 注入背景参数（复用既有机制）
  - [x] `SettingsWindow` 外观面板新增"相册背景"配置区（含浏览图片按钮）

## 📊 P2 中期功能：可插拔数据组件（Widget）

设计原则：组件独立，任意表盘自由开启 / 关闭，不耦合单一表盘

- [x] 日期组件：公历、农历、星期、节气
- [x] 系统监控组件
  - [x] CPU 使用率、内存占用
  - [x] 实时上下行网速
  - [x] 笔记本电池电量
  - [ ] 拓展（可选）：CPU 温度，接入 OpenHardwareMonitor
- [x] 天气组件（对接免费公共天气 API）：温度、天气图标、日出日落
- [x] 小型工具组件
  - [x] 自定义倒计时
  - [x] 单行滚动待办文字
